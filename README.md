# Student Management System

A web-based Student Management System built using **Python Flask and MongoDB** to simplify academic management.

## Features

- Student and Teacher Authentication
- Separate Student and Teacher Dashboards
- Profile Management
- Assignment and Project Submission
- Attendance Management
- Student Records
- Lecture History

## Tech Stack

- **Backend:** Python, Flask
- **Database:** MongoDB
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
